# About GreenPrints

**GreenPrints** is an app that calculates CO₂ emissions based on a given flight route. It aims to raise awareness of the environmental impact of air travel and help users make informed decisions about their carbon footprint. You can access the live application here: [GreenPrints](https://greenprints.netlify.app/).

## Features

- **Flight Route CO₂ Calculator**: Input your flight route to calculate the estimated CO₂ emissions.
- **Environmental Awareness**: Provides insights into the environmental impact of air travel.
- **User-Friendly Interface**: Designed with simplicity and usability in mind.
